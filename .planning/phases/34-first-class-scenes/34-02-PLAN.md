<objective>
Prove and finalize controller-less scene apply (D-05) and clean up the remnants of the old controller-owned-scenes schema.

The engine already gates MC6 programming on `if rig and rig.controller and not scene and not device_filter` (apply.py line 170), so a rig with no CONTROLLER device already skips controller programming and still applies device presets. This plan adds the missing test coverage for that path, removes the now-unnecessary `hasattr(rig, "scenes")` defensive guard in `MC6Device.apply()` (scenes is always a real field after 34-01), and confirms the loader docs reflect the new schema.

Purpose: Lock in D-05 with a regression test and remove dead compatibility code so the model change from 34-01 is fully realized.

Output: A controller-less apply test, a cleaner `MC6Device.apply()`, and a final green `make test` + `make lint`.

Depends on 34-01: `Rig.scenes` must be a real field (populated via `Rig(scenes=...)`) before the controller-less apply test can construct a rig with scenes but no controller.
</objective>
